# game_companion

Create a mobile-first, premium landing page for a web application called "Chowkabara Companion", designed as the digital companion for the traditional Indian board game Chowkabara.

The visual identity should blend Indian heritage with modern minimalism. Avoid stereotypical temple art or excessive decoration. The interface should feel elegant, premium, and intuitive for children and families.

Color Palette:

 Primary: Earth Brown (#6B4F3A)

 Accent: Marigold Gold (#D9A441)

 Secondary: Forest Green (#355E3B)

 Background: Warm Ivory (#F8F3E8)

 Occasional Accent: Terracotta (#C76B4A)

Use Cinzel for headings and Poppins for body text. Apply rounded cards, subtle shadows, soft transitions, and generous spacing. The background should include a very light handmade paper texture with faint Indian geometric motifs in the corners.

The page should include:

 Centered logo placeholder

 App title: "Chowkabara Companion"

 Subtitle: "Play • Learn • Preserve Heritage"

 Large "Continue with Google" button (Google branding style)

 Divider labeled "OR"

 Activation Code input field with placeholder "Enter Activation Code"

 Primary button labeled "Join Game"

 Footer text: "Inspired by India's Traditional Games"

Design exclusively for a mobile viewport with excellent responsiveness. Use smooth fade and slide animations for the initial load. Build the page with reusable React components and clean routing so future pages can reuse the same design system.
